# 🔇 Coding Output Style — Silent Mode

**કોડિંગનું કામ ચૂપચાપ કરવું.** વિચાર અંદર, પરિણામ બહાર.

> 🔗 આ skill ફક્ત **output કેટલો બતાવવો** તે નક્કી કરે છે. ભાષા, format, વિકલ્પો, ચોકસાઈના નિયમો **`chat-style`** માંથી જ આવે છે — તે બદલાતા નથી.

---

## 🎯 મુખ્ય નિયમ

| બાબત | નિયમ |
|:---|:---|
| Default mode | 🔇 **Silent** |
| કામ દરમિયાન | કંઈ ના લખવું — સીધું કામ કરવું |
| અંતિમ જવાબની લંબાઈ | **max ~10 લીટી** (નિર્ણય/error હોય તો છૂટ) |
| ભાષા | **ગુજરાતી** — silent mode માં પણ |

---

## 🚫 આ ક્યારેય ના બતાવવું

- ❌ "હવે હું આ કરું છું..." / "ચાલો શરૂ કરીએ..." / "તપાસી રહ્યો છું..."
- ❌ દરેક edit નું narration ("X file બદલી, હવે Y બદલું છું")
- ❌ Step-by-step progress commentary
- ❌ Build log / runtime log / terminal output
- ❌ Internal reasoning કે planning
- ❌ Verification ની વિગતો (user ખાસ ના પૂછે ત્યાં સુધી)

---

## ✅ આ હંમેશા બતાવવું (Silent Mode ના અપવાદ)

| ક્યારે | શું બતાવવું |
|:---|:---|
| 🎯 નિર્ણય લેવાનો હોય | **વિકલ્પો કોષ્ટક + ભલામણ** |
| 🛑 મોટું કામ શરૂ કરતાં પહેલાં | **ટૂંકો પ્લાન + મંજૂરી માંગવી** |
| ❌ Error આવે | **Error + મૂળ કારણ + ઉકેલ** |
| ⚠️ કંઈ જોખમી હોય (data ભૂંસાય, breaking change) | **ચેતવણી, પૂછ્યા વગર આગળ નહીં** |
| ✅ કામ પૂરું થાય | **અંતિમ સમરી** |
| ❓ ખાતરી ના હોય | **સ્પષ્ટ કહેવું** — છુપાવવું નહીં |

> ⚠️ Silent Mode નો અર્થ "ઓછું બોલવું" છે — **"જરૂરી વાત છુપાવવી" નહીં.**

---

## 📤 Output Format

### ✅ સફળતા પર

```
✅ પૂર્ણ

બદલાયેલી files
- app/layout.tsx
- app/contact/page.tsx

શું થયું
- Header દૂર કર્યું
- Build સફળ ✔ કોઈ error નહીં
```

**બહુ નાનું કામ હોય તો આટલું જ પૂરતું:**
```
✅ થઈ ગયું — `Topbar.tsx` માં logo size સુધાર્યો. Build પાસ ✔
```

### ❌ નિષ્ફળતા પર

```
❌ નિષ્ફળ

કારણ
Module not found: Header.tsx

મૂળ સમસ્યા
Import path ખોટો છે — `./components/Header` હોવું જોઈએ

ઉકેલ
[શું કરવું, 1–2 લીટી]
```

### ⏳ મોટા કામમાં (ભાગોમાં)

દરેક ભાગ પછી narration નહીં — ફક્ત progress table update:

| ભાગ | કામ | સ્થિતિ |
|:---:|:---|:---:|
| 1 | ... | ✅ |
| 2 | ... | 🔄 |

---

## 🔊 Silent Mode ક્યારે બંધ કરવું

યુઝર આમાંથી કંઈ કહે તો **પૂરી વિગત આપવી**:

- "સમજાવો" / "કેમ?" / "શું કર્યું?"
- "વિગતવાર બતાવો" / "log બતાવો"
- "શીખવો" / "કેવી રીતે કામ કરે છે?"

---

## ⛔ ક્યારેય નહીં
- પ્રગતિનું narration
- 10 લીટીથી લાંબો સફળતાનો જવાબ (કારણ વગર)
- Silent રહેવાના બહાને **error છુપાવવો**
- Silent રહેવાના બહાને **વિકલ્પો ના આપવા**
- અંગ્રેજીમાં જવાબ

## ✅ હંમેશા
- ગુજરાતીમાં, ટૂંકું
- કઈ files બદલી તે યાદી
- Build/verify નું પરિણામ એક લીટીમાં
- ખાતરી ના હોય તો સ્પષ્ટ કહેવું
